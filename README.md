# Currículo - Eduardo Simões

Bem-vindo ao repositório do meu currículo online! Este projeto foi desenvolvido para apresentar minhas qualificações, experiências, projetos e informações de contato de uma forma moderna, interativa e visualmente agradável.

**🚀 Acesse o site:** [https://cveduardosimoes.web.app](https://cveduardosimoes.web.app)

---

## 🌟 Sobre o Projeto

Este site é uma representação digital do meu perfil profissional. Ele foi construído com o objetivo de ser uma plataforma dinâmica e de fácil navegação, permitindo que recrutadores e interessados conheçam mais sobre minha trajetória e habilidades.

---

## ✨ Funcionalidades Principais

* **Navegação Intuitiva:** Interface clara e organizada para fácil acesso às informações.
* **Redes Sociais:** Botões clicáveis que redirecionam diretamente para meus perfis em diversas redes sociais (LinkedIn, GitHub, etc.).
* **Toggle Theme (Dark/Light Mode):** Funcionalidade que permite ao usuário alternar entre um tema claro e um tema escuro, adaptando a visualização conforme sua preferência e conforto visual.
* **Cards Descritivos:** Seções com cards detalhando minhas experiências profissionais, projetos realizados, formação acadêmica e habilidades.
* **Design Responsivo:** Totalmente adaptável a diferentes tamanhos de tela (desktops, tablets e smartphones).

## ⚙️ Como Executar Localmente (Opcional)

Se você deseja executar este projeto localmente, siga os passos abaixo:

1.  **Clone o repositório:**
    ```bash
    git clone https://github.com/dudusimeos/cveduardosimoes.git
    ```
2.  **Navegue até o diretório do projeto:**
    ```bash
    cd cveduardosimoes
    ```
3.  **Npm install e em seguida Npm start.**
